\startalignment[middle]
  {\tfd Arrow Length Axis in Mayfair}
\stopalignment
\blank[small]

Mayfair attempts to keep horizontal arrows all the same length where reasonably possible, with the
exception of "Long Arrows" that are, well, longer.

Mayfair has an Arrow Length axis that controls the default length of arrows.  The following table indicates at the ranges of this axis for which
horizontal arrows will have the same width.  An X in the table indicates that at this range those arrows will have the same width as all other arrows that are also in a row with an X.

It is remarked that Mayfair also has a width axis that slightly changes the lengths of the arrows, but that is not relevant for this table.

All of this is probably much more than one might want to know, or ever need to think about.
