Somerville is a work-in-progress Opentype mathematics font designed by Julius Ross to accompany Playfair designed by Claus Eggers Sørensen.  It is intended to be used in {\CONTEXT} where it has received the most testing, but can also be used in other systems such as {\LATEX}.     The font is not expected at present to be useful for actual mathematics documents since it remains incomplete in many ways, the most serious being a lack of greek characters.

\part{Variation}

Somerville experiments with combining OpenType variation and the OpenType mathematics table\footnote{It is noted that a variable MATH table is not an Opentype standard}, allowing the following features to be adjusted:

\startitemize
\item Weight, Width and Optical Size 
\item Integral Slant
\item Arrow Length and Arrow Head
\item Math Weight (for the Mathematical Bold letters)
\stopitemize

\section{Simple Usage in ConTeXt}
The simplest usage in {\CONTEXT} is with

\starttyping
\input type-imp-somerville.mkxl
\setupbodyfont[somerville]
\stoptyping

\noindent To select mathematics features set \type{mathextra} before loading the typescript

\starttyping
\definefontfeature[mathextra][{ss16=yes,ss17=yes}]
\input type-imp-somerville.mkxl
\setupbodyfont[somerville]
\stoptyping

\section{Instances in ConTeXt}

Other instances of the font are named as follows:
\starttyping
somerville-OPTICALSIZE[-WIDTH][-WEIGHT]
\stoptyping
\noindent where the square brackets indicate optional terms.  The options are:
\startitemize
\item \type{OPTICALSIZE} is one of \type{micro}, \type{minuscule}, \type{miniature}, \type{caption}, \type{regular}, \crlf \type{subheading}, \type{trumpet}, \type{headline}, \type{display}, \type{titling}, \type{hairline}.
\item \type{WIDTH} is one of \type{semicondensed} or \type{semiexpanded}; omit this for regular width.
\item \type{WEIGHT} is one of \type{semilight}, \type{medium}, \type{semibold}, \type{bold}, \type{extrabold}, or \type{black}; omit this for regular weight.
\stopitemize
\noindent For example: 
\noindent \starttyping
\setupbodyfont[somerville-regular-semiexpanded-bold]
\setupbodyfont[somerville-regular-semicondensed]
\setupbodyfont[somerville-micro,5pt]
\stoptyping
\noindent In particular \type{somerville-regular} selects regular optical size, width, and weight and \type{somerville} is an alias for this instance.

\section{Custom Axes Values in ConTeXt}

For a custom axes values use the function \type{\setupSomerville}.  Its first argument lists the axis settings; the second names the new typeface. 
\starttyping
\setupSomerville
  {Width=106,Weight=400,Optical Size=12,Math Weight=750,
   Arrow Length=100,Arrow Head=100,Integral Slant=50}
  {somerville-custom}
\setupbodyfont[somerville-custom, 12pt]
\stoptyping

\noindent The optical size value is independent of the point size: \type{Optical Size=12} selects the optical sizing designed for 12 point text, while \type{12pt} sets the size of the text.  These do not have to agree, so this is also valid
\starttyping
\setupbodyfont[somerville-custom, 22pt]
\stoptyping

\noindent Axis values can also use the names in the reference tables
\starttyping
\setupSomerville
  {Width=Regular,Weight=Medium,Optical Size=15,
   Arrow Head=188, Integral Slant=Slanted}
  {somerville-customtwo}
\setupbodyfont[somerville-customtwo]
\stoptyping

\noindent It is also possible to start from a name instance and override individual axes, and set features:
\starttyping
\definefontfeature[myfeatures][ss17=yes]
\setupSomerville
  {instance=micro-semicondensed,Arrow Head=200,mathfeatures=myfeatures}
  {somerville-micro-semicondensed-largearrowheads}
\setupbodyfont[somerville-micro-semicondensed-largearrowheads]
\stoptyping

\section{Usage in LaTeX}

At present other typesetting systems do not support variable mathematics, so to use Somerville you need to create static fonts using \type{instantiate_somerville.py}.

The following commands list the available instances and give an example export:
\starttyping
python3 instantiate_somerville.py --list-instances
python3 instantiate_somerville.py somerville-regular
\stoptyping
\noindent The script produces a static mathematics font and \type{.fontspec} file that can be used in LuaLaTeX.   It is also possible to set the axes manually.  Use 
\starttyping python3 instantiate_somerville.py --help\stoptyping 
\noindent to see how to do this.   Here is a sample usage in {\LaTeX}:
\starttyping
\documentclass{article}
\usepackage{unicode-math}
\input{SomervilleRegular.fontspec}
\setmainfont{SomervilleRegular}
\begin{document}
Here is some text in Playfair and  \text{ ome bold text} 
and \emph{some italic text}.  Here is some mathematics in Somerville:
\[
    \nabla\times\symbf{E} = -\frac{\partial\symbf{B}}{\partial t}
\]
\end{document}
\stoptyping
